An intel channel is where you and your friends share sightings, like “5 hostiles in 1DQ1-A” or “Amamake clear”. Every report shows on the map for everyone in the channel for half an hour, and a route through a reported system points it out.

You can add reports three ways: type them on the channel's page or the map, paste lines from an in-game intel chat, or let EveSynapse Axon send them for you while you play.

EveSynapse Axon

Axon is a small program you run on your own computer. EVE already saves your chat to files on your computer. While you play, Axon reads those files for your in-game intel channel and sends each new line here, so sightings show up on the map without anyone typing or pasting them. It is open source.

Set it up

  1. Install Axon. Download the file for your computer and run it. It installs itself and opens Axon's window. {{if not .Tokens}}
    {{range .Downloads}}{{.Label}}{{end}}

    Axon isn't code-signed yet, so Windows may warn about an unknown publisher: choose More info, then Run anyway. On a Mac, make the download runnable with chmod +x and run it once from Terminal.

    {{end}}
  2. Pair it with your account. Make a pairing code below. In Axon, under EveSynapse, enter this site's address{{if .SiteAddr}} ({{.SiteAddr}}){{end}} and the code, then click Pair. That's it. Axon remembers it from then on, and there's nothing for you to copy, save or set up.
  3. Link your in-game channel. In Axon's channel list, pick your in-game intel channel and the intel channel here it should post to. If both have the same name (say, “Delve Intel” in game and here), Axon links them for you. Axon can post only to channels where you can post.
  4. Start watching, then play. Click Start watching. Stay in the in-game channel and leave Axon running (on Windows it waits in the system tray). New lines that name a system become reports here within a few seconds.

Questions

What exactly does Axon read?
Only the chat log files EVE writes to your computer (in Documents\EVE\logs\Chatlogs), and only for the in-game channels you link. Not your screen, the game, or any other files. EVE saves these logs unless chat logging was turned off in its settings.
What does it send here?
Each new line from a linked channel, as it appears. A line that names a system becomes a report with the count, “clear”, who said it and when. Lines that name no system, like chatter and questions, are dropped. Nothing from before you started watching is sent.
Do I need a config file?
No. Axon saves its own settings. You never need to open, edit or copy anything.
Do I need to do anything after pairing?
No. The pairing only works on the computer you paired, so it can't be copied somewhere else. To stop a computer from posting, remove it below.
Several computers, or several characters?
Pair each computer once. If two of your characters are in the same in-game channel, each line is still posted only once.
