Report a bug

Two ways in. Report it on the EveSynapse Discord, in the bug reports channel, or email bugs@evesynapse.app if you do not use Discord.

A useful report says:

  • what you were doing
  • what you expected to happen
  • what happened instead

A screenshot helps, if you have one.

Request a feature

Feature requests live on the EveSynapse Discord, in the feature requests channel.
